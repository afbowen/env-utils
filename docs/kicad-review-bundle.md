# kicad-review-bundle

Collect the useful files from the current KiCad project into a ZIP for design review.

Run from a KiCad project directory:

```bash
kicad-review-bundle
```

Includes available KiCad project/PCB/schematic files, PDFs, BOM/CSV exports, DRC reports, and STEP/STP models while skipping missing files and KiCad autosaves.
